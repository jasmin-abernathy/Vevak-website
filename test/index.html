Étape 1 sur 6 Télécharger le fichier
1⬇️

Téléchargement

Télécharge l'APK

Appuie sur « Télécharger VeVak (.apk) ». Ton navigateur peut te prévenir qu'un fichier APK peut présenter un risque.

💬
Tu peux voir quelque chose comme :
« Ce type de fichier peut endommager votre appareil » ou « Voulez-vous quand même télécharger ce fichier ? »
✅ Ici, c'est attendu. Tu viens toi-même de demander le fichier depuis l'espace privé VeVak : confirme uniquement ce téléchargement.
Mon téléphone affiche autre chose

Si ton navigateur te demande simplement Annuler / Télécharger quand même / Conserver, choisis l'option qui conserve le fichier. Si le message parle explicitement d'un logiciel malveillant détecté, ne continue pas et fais une capture.

2📂

Ouverture

Ouvre le fichier téléchargé

Appuie sur la notification de téléchargement, ou ouvre l'application Fichiers / Mes fichiers / Téléchargements, puis touche VeVak-foss-test.apk.

💬
Message fréquent :
« Pour votre sécurité, votre téléphone n'est pas autorisé à installer des applications inconnues provenant de cette source. »
✅ C'est exactement l'étape attendue. Choisis Paramètres si Android te le propose.
Je ne retrouve pas le fichier

Ouvre ton application de fichiers puis le dossier Téléchargements / Downloads. Le nom attendu est VeVak-foss-test.apk. Tu peux aussi relancer le téléchargement depuis le haut de cette page.

3🔓

Autorisation temporaire

Autorise cette source, juste pour l'installation

Dans l'écran de réglages ouvert par Android, active « Autoriser depuis cette source » pour l'application qui a ouvert l'APK : Chrome, Firefox, Fichiers, Mes fichiers…

⚙️
Si tu dois chercher le réglage manuellement :
Paramètres → Applications → Accès spécial → Installer des applis inconnues
🔐 Cette permission n'est pas donnée à VeVak. Elle autorise seulement ton navigateur/gestionnaire de fichiers à lancer l'installation.
Je ne trouve pas « Autoriser depuis cette source »

Utilise la recherche des Paramètres avec les mots applications inconnues, sources inconnues ou installer des applis inconnues. Sur certains Samsung, le menu peut se trouver dans Sécurité et confidentialité.

4🌱

Installation

Installe VeVak

Reviens à l'APK si Android ne le fait pas automatiquement. Un écran doit afficher le nom VeVak avec un bouton Installer.

🛡️
Play Protect peut maintenant proposer une analyse.
Tu peux et tu devrais laisser cette analyse se faire.
✅ Proposition d'analyse = normale. Attends son résultat avant de continuer.
Android me demande un code / empreinte

C'est simplement la confirmation de sécurité de ton téléphone. Utilise ton verrouillage habituel uniquement si l'écran système te le demande.

5🛑

Point de sécurité

Lis le résultat de Play Protect

Il y a une différence entre « application inconnue, analyser ? » et « application dangereuse détectée ».

✅ Analyse proposée / aucun problème détectéTu peux poursuivre l'installation.
🛑 Danger détecté / installation bloquéeArrête ici. Ne cherche pas « installer quand même ». Fais une capture et préviens-moi.
Je ne sais pas dans quel cas je suis

Si Android emploie des termes comme dangereuse, malveillante, risque détecté ou bloque explicitement l'app pour ta sécurité, arrête le test. Si Android indique seulement qu'il ne connaît pas encore l'application et souhaite l'analyser, laisse-le faire.

6🔒

Dernière étape

Retire l'autorisation d'installation

Une fois VeVak installée, retourne dans Installer des applis inconnues et désactive « Autoriser depuis cette source » pour Chrome/Fichiers.

✨ C'est fini. Cette permission ne sert plus à rien pour utiliser VeVak normalement.
Je préfère le faire plus tard

Tu peux ouvrir VeVak avant, mais pense à revenir désactiver cette permission. Elle concerne toutes les futures APK ouvertes depuis cette même application, pas seulement VeVak.

🎉

Installation terminée

VeVak est installé.

Tu peux maintenant ouvrir l'application. Les permissions qu'elle demande ensuite concernent son fonctionnement, pas l'installation hors Play.
